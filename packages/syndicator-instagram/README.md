# @postr/syndicator-instagram

> **Alpha:** this is the postr 2.0 rewrite and its API may still change. Install it with
> `npm install @postr/syndicator-instagram@alpha`; `npm install @postr/syndicator-instagram` gives the stable 1.x release.

Syndicates photo posts and likes to Instagram.
