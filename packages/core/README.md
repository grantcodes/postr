# @postr/core

> **Alpha:** this is the postr 2.0 rewrite and its API may still change. Install it with
> `npm install @postr/core@alpha`; `npm install @postr/core` gives the stable 1.x release.

A library-first IndieWeb backend for Node.js: a Micropub server, media endpoint and typed post API on a single SQLite file.

Documentation: https://postr.dev/guide/getting-started
