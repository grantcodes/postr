# @postr/syndicator-telegram

> **Alpha:** this is the postr 2.0 rewrite and its API may still change. Install it with
> `npm install @postr/syndicator-telegram@alpha`; `npm install @postr/syndicator-telegram` gives the stable 1.x release.

Syndicates postr posts to a Telegram channel.

Documentation: https://postr.dev/guide/plugins#telegram
