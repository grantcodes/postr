# @postr/syndicator-superfeedr

> **Alpha:** this is the postr 2.0 rewrite and its API may still change. Install it with
> `npm install @postr/syndicator-superfeedr@alpha`; `npm install @postr/syndicator-superfeedr` gives the stable 1.x release.

Sends WebSub publish pings (Superfeedr or any hub) when postr posts are published.

Documentation: https://postr.dev/guide/plugins#superfeedr-websub
