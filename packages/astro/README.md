# @postr/astro

> **Alpha:** this is part of the postr 2.0 rewrite and its API may still change. Install it with
> `npm install @postr/astro@alpha`.

Astro content loaders for postr: build-time and live collections of your posts, read from a postr
instance, its database or its Micropub endpoint.

Documentation: https://postr.dev/guide/astro
