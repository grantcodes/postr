# @postr/plugin-feeds

> **Alpha:** this is the postr 2.0 rewrite and its API may still change. Install it with
> `npm install @postr/plugin-feeds@alpha`; `npm install @postr/plugin-feeds` gives the stable 1.x release.

RSS, Atom, JSON Feed, JF2 and mf2 feeds for postr.

Documentation: https://postr.dev/guide/plugins#feeds
