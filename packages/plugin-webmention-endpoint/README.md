# @postr/plugin-webmention-endpoint

> **Alpha:** this is the postr 2.0 rewrite and its API may still change. Install it with
> `npm install @postr/plugin-webmention-endpoint@alpha`; `npm install @postr/plugin-webmention-endpoint` gives the stable 1.x release.

Receives webmentions and stores them on the target post as likes, reposts, bookmarks, comments or mentions.

Documentation: https://postr.dev/guide/plugins#webmention-endpoint
